# 🏐 KOVO 여자배구 정규리그 순위 및 최종 승점 예측 프로젝트 (Data Spike)

  * 2017-2018 시즌부터 2024-2025 현재 진행 중인 시즌까지의 한국배구연맹(KOVO) 여자부 정규리그 데이터를 종합 분석.

## 🧹 4. 데이터 수집 및 전처리 (Data Acquisition & Preprocessing)

### 1) 데이터 수집 (Data Acquisition)
- **수집 대상**: KOVO 공식 웹사이트 내 V-리그 여자부 정규리그 데이터
  - **시즌별 팀 순위 데이터**: 승점, 승/패, 득세트, 실세트, 세트득실률, 득점, 실점, 점수득실률, 연속 승패 기록 등
  - **라운드별 데이터**: 1 Round ~ 6 Round 상세 성적
  - **부문별 팀 순위 데이터**: 공격(오픈, 시간차, 이동, 후위, 속공, 퀵오픈), 서브, 블로킹, 범실 등의 기록

### 2) 데이터 전처리 및 변수 변환 (Feature Engineering)
- **연속(Streak) 컬럼 수치 변환**: 
  - 문자열 'N승'은 positive integer (`+N`), 'N패'는 negative integer (`-N`)로 변환 (`연속_수치`).
- **시즌(Season) 컬럼 변환**: 
  - '23-24' 형식의 문자열에서 시작 연도를 추출하여 수치형 연도(예: `2023`)로 변환.
- **팀명 원-핫 인코딩(One-Hot Encoding)**: 
  - 범주형인 `팀` 컬럼을 `팀명_GS칼텍스`, `팀명_IBK기업은행`, `팀명_정관장`, `팀명_페퍼저축은행`, `팀명_한국도로공사`, `팀명_현대건설`, `팀명_흥국생명` 7개 인코딩 컬럼으로 펼치고 기존 컬럼 삭제.

## 📊 5. 데이터 분석과정 및 모델 설계 (Data Analysis & Modeling)

### 1) 다중상관분석(Multi-Correlation Analysis)을 통한 독립변수 선정
종속변수 `순위`와 상관계수를 계산하여 모델 2가지를 비교 검증:
- **Model 1 (|상관계수| $\ge$ 0.6)**: 
  - 독립변수: 승점, 승, 패, 득세트, 실세트, 세트득실률, 점수득실률, 공격_순위, 공격성공률, 서브_순위 (10개)
- **Model 2 (|상관계수| $\ge$ 0.7)**: 
  - 독립변수: 승점, 승, 패, 득세트, 실세트, 세트득실률, 점수득실률, 공격_순위 (8개)

#### 📐 Model 1 vs Model 2 성능 비교
| 평가 지표 | Model 1 (|r| $\ge$ 0.6) | Model 2 (|r| $\ge$ 0.7) |
| :--- | :--- | :--- |
| **Train $R^2$ Score** | 0.9089 (0.909) | 0.9085 (0.909) |
| **Test $R^2$ Score** | 0.6969 (0.697) | **0.7105 (0.711)** |
| **Test MSE** | 1.063 | **1.015** |

*Test $R^2$가 더 높고 MSE 오차가 더 적은 **Model 2**를 순위 예측 기본 모델로 채택.*

---

### 2) 접근 방식 A: 팀 성적 지표 기반 2024-2025 최종 순위 예측
- **분석 결과**: 2024-2025 현재 진행 중인 시즌 데이터 적용 시, 1위와 2위의 순위 역전 발생.
  - **현재 시즌 순위**: 1위 흥국생명, 2위 현대건설
  - **예측 최종 순위**: **1위 현대건설**, **2위 흥국생명**
  - **역전 원인 분석**: 현재 진행 중인 24-25 시즌에서 공격순위를 비롯한 득점 지표(공격 성공률 및 세트당 지표 등)가 현대건설이 흥국생명보다 우위에 있어 다중 회귀 모델이 현대건설의 최종 1위를 예측함.
  - **기타 순위 변경**: 정관장(현 3위)과 IBK기업은행(현 4위) 간의 3-4위 역전 예측.

---

### 3) 접근 방식 B: 경기당 기대 승점(Winscore Per Match) 예측 모델

#### 💡 기획 의도 ("5꽉률" 및 비선형성 대응)
1. **배구 승점 부여 규칙**: 3:0/3:1 승리 시 3점, 3:2 승리 시 2점, 2:3 패배 시 1점, 0:3/1:3 패배 시 0점을 부여하는 특이 규칙("5꽉률") 존재.
2. 승패 수 및 승률이 승점/순위로 직관적으로 연결되지 않아 데이터 비선형성 문제가 발생.
3. 이를 해결하기 위해 순위를 직접 맞추기보다 **"경기당 기대 승점"**을 예측하여 최종 승점을 계산하는 모델 구축.

#### 📐 7팀 체제 데이터 선별 이유
- 20-21시즌(6개 팀)에서 21-22시즌(페퍼저축은행 참가로 7개 팀)으로 바뀌면서 리그 데이터 특성에 큰 변화 발생.
- 6개 팀 데이터 학습 시 오차 곡선이 컸으나, **21-22시즌 이후 7개 팀 데이터만 학습에 활용**했을 때 Actual vs Prediction 오차가 획기적으로 줄어듦.

#### 📌 기대 승점 예측 독립변수 및 종속변수
- **독립변수**: 누적 수치가 아닌 경기당/세트당 비율 및 평균 지표 활용
  - `세트득실률`, `점수득실률`, `공격성공률`, `서브_세트당평균`, `블로킹_세트당평균`
- **종속변수**: `기대승점 = 실제 팀 승점 / 경기 수`
- **최종 예측 승점 계산식**: `총 예측 승점 = 경기 수 × 경기당 예상 승점`

## 🛠 7. 기술적 도전 및 트러블슈팅 (Troubleshooting)

### 1. Selenium 수집 로직 재설계 (동적 웹/비정형 데이터 대응)
- **문제점**: KOVO 홈페이지의 동적 테이블 렌더링 및 시즌별 표 구조 변경으로 데이터 누락 및 수집 에러 발생.
- **해결 방안**: 특정 요소가 로드될 때까지 기다리는 `WebDriverWait`를 도입하고 HTML 구조를 심층 파싱하도록 수집 로직 재설계.
- **결과**: 데이터 유실률 **0%** 달성 및 확장성 확보.

### 2. 리그 구단 수 변경에 따른 데이터 학습 범위 최적화
- **문제점**: 6개 팀 시절(20-21 이전) 데이터 포함 시, 7개 팀 체제의 실제 승점 곡선과의 오차 급증.
- **해결 방안**: 7개 팀 체제(페퍼저축은행 합류 이후 21-22~23-24) 데이터만 선별하여 회귀 모델 학습 진행.
- **결과**: Actual vs Prediction 예측 오차 대폭 감소.

## 🚀 8. 프로젝트 한계 및 발전 방향 (Future Improvements)

1. **라운드 데이터 결합 자동화**: 
   - 23-24 시즌 데이터 결합 시 라운드 데이터 통합의 제약이 존재했던 점을 보완하여, 향후 전체 시즌 및 라운드 데이터 파이프라인 자동화 구현 고려.
2. **머신러닝 모델 확장 및 분류/회귀 비교**:
   - **KNN Classifier 적용**: `KNeighborsClassifier(n_neighbors=10)`로 분류 시 정확도 Accuracy가 **0.44**로 다소 낮게 나타남.
   - **로지스틱 회귀(Logistic Regression) 적용**: `multi_class='multinomial'` 적용 시 Accuracy가 **0.56**으로 측정됨.
   - **결론**: 단순 분류 알고리즘보다는 **다중 선형 회귀(Linear Regression)**를 이용한 기대 승점 수치 예측 접근법이 오차가 적고 본 과제에 훨씬 적합함을 확인.
